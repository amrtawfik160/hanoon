# Triage Labels

The engineering skills use five canonical triage roles. Their tracker labels are:

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue is waiting for information. |
| `ready-for-agent` | `ready-for-agent` | The issue is decision-complete and ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or action. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Use one readiness role at a time. Wayfinder type labels describe decision work and do not replace readiness.
