# Task rigor only escalates

Hanoon selects and versions a task recipe from durable task traits at admission. New risk, scope, or failure evidence may move the job to a more protective compatible recipe, but neither a worker nor a retry may silently downgrade it; material changes in scope or authority return to the owner. This can spend more time after a conservative escalation, but it prevents retries and model judgment from eroding already-established safeguards.
